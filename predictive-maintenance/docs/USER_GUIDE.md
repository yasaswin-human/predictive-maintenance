# User Guide

- Overview: dataset size, class balance, test metrics.
- Live Monitoring: start/pause/stop/step a simulated sensor stream.
- Manual Prediction: enter six features, get probability + risk + notes.
- Batch Analysis: upload a CSV with the six feature columns.
- Model Performance: test metrics, confusion matrix, per-candidate comparison,
  ROC / PR curves.
- Alerts & Maintenance History: filter, acknowledge, export.
- About & Dataset: objective, dataset, model, disclaimer.
